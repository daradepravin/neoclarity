# NeoClarity UI (React + TypeScript + Vite)

Connects to the Spring Boot API on port 8080.

## Quick start

```bash
npm install
npm run dev
# Opens on http://localhost:3000
```

Vite proxies `/api/*` to `http://localhost:8080` automatically.

## Pages
- `/dashboard` — Clarity Score, Next Best Action, Accounts
- `/goals` — Goal tracking and creation
- `/events` — Life event detection and confirmation (Yellowstone!)
- `/recommendations` — Full recommendation list with approve/dismiss
- `/profile` — Consent management, connected accounts
