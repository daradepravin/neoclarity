# NeoClarity — Financial Resilience Platform

AI-powered Open Banking platform. Mphasis FDE Bootcamp capstone.

## Stack
- `neoclarity-api` — Spring Boot 3.3, Java 21, PostgreSQL, JWT auth
- `neoclarity-ui` — React 18, TypeScript, Vite
- `neoclarity-agent` — FastAPI, LangGraph, Neo4j AuraDB, Claude API (Week 5 — coming)

## Quick start
```bash
# API
cd neoclarity-api && mvn spring-boot:run

# UI (new terminal)
cd neoclarity-ui && npm install && npm run dev
```
